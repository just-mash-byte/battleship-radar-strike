# 📡 Battleship: Radar Strike

A radar/sonar-themed Battleship game — built for WIG 2026 Hackathon #02.

## Features
- Manual fleet placement (click to place, rotate, or auto-place)
- 5 classic ships: Carrier, Battleship, Cruiser, Submarine, Destroyer
- vs AI Commander with 3 difficulty levels (Easy/Medium/Hard — hard AI hunts adjacent cells after a hit)
- Radar sweep animation on enemy grid
- Hit/miss/sunk visual feedback
- Sound effects + mute toggle
- Live shot counter & game timer
- Animated "How to Play" demo
- Fully mobile responsive

## Run locally
```sh
python3 -m http.server 8000
```
Open `http://localhost:8000`
